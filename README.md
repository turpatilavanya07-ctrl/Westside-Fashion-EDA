# Westside Fashion EDA

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a Westside fashion product dataset.

The dataset contains information about fashion products such as product name, price, category, and subcategory.

## Dataset

The dataset contains **6915 fashion product records** with the following attributes:

- Product Name
- Price
- Product URL
- Image URL
- Category
- Subcategory

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Steps

1. Importing the dataset
2. Understanding the dataset
3. Checking missing values
4. Checking duplicate records
5. Data cleaning
6. Price conversion
7. Exploratory Data Analysis
8. Data visualization
9. Feature analysis
10. Fashion category analysis
11. Machine Learning using Logistic Regression
12. Model evaluation
13. Product category prediction

## Machine Learning

Logistic Regression is used to classify fashion products into **Men** and **Women** categories based on product names.

TF-IDF Vectorization is used to convert product names into numerical features.

## Model Performance

The Logistic Regression model achieved approximately **99.93% accuracy** on the test data.
